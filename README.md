# KOKO 唤醒器

KOKO Windows 桌宠的 TT / SillyTavern 原生扩展，不依赖酒馆助手脚本。

## 安装

1. 在酒馆「扩展 → 安装扩展」填写 `https://github.com/ichiko00/KOKO-Waker`。
2. 停用旧的 KOKO 唤醒器酒馆助手脚本，刷新酒馆。
3. 从输入框下方的扩展菜单打开「KOKO 唤醒器」。
4. 展开「连接设置」，填写桌宠地址（默认 `http://127.0.0.1:17864`）和配对码 `clientToken`；也可以选择当前桌宠 `koko-bridge/config.json` 自动填入。
5. 保存设置，点击「开启同步」。关闭面板后继续同步，刷新后记住设置。

已有脚本版用户：在同一个酒馆地址下使用时，会沿用原来的连接设置和同步开关。不要同时运行脚本版和扩展版。

## 功能

- 同步当前聊天最近完整正文，排除分析及可执行脚本。
- 从桌宠主动发送消息，核对聊天、生成状态与已有草稿。
- 沿用 MyPhone 的语音 API、角色配音和整篇朗读设置，支持播放、暂停、继续、停止。
- 居中面板内修改接口地址和配对码，自动重连。
- 桌宠新版支持 `<branches>` 剧情选项：整段朗读完成后显示收起的思考气泡，点击展开，再点击选项直接发送。支持 A.、B. 或数字编号，以及 details/summary 包裹；切换聊天、改写正文和已有草稿会拦截过期发送。
- 从桌宠播放时，会将 branches 加入小手机整篇朗读的跳过标签，保留其他配置；分支不加入朗读正文。
- 新版桌宠胶囊播放器支持后退/前进 15 秒，使用小手机朗读小窗的现有跳转控制。仅音频就绪并且可跳转时启用；可在小手机开启朗读小窗。右键桌宠播放器可停止朗读。

需同时运行 KOKO 桌宠和本地桥接服务；本扩展不包含桌宠程序。朗读需要启用 MyPhone，并在酒馆打开一次小手机；小手机需开启「整篇朗读」，旁白选择角色配音。

仅支持同一台电脑上的本地服务。手机上的 127.0.0.1 不代表 PC。

## 更新

扩展声明了 `auto_update`，更新行为由 TT / ST 宿主决定。普通刷新只加载本机已有文件，不等于每次都从 GitHub 下载。
最稳妥的步骤：扩展管理中检查并更新 KOKO 唤醒器，然后刷新页面。无需重新导入 JSON，连接设置保留。

## 数据

仓库不包含配对码、API 密钥、聊天记录或个人配置。连接地址和客户端配对码保存在当前酒馆站点的 localStorage 中；读取 config.json 时只保留 port 和 clientToken，不保存 controlToken。聊天正文仅通过本机连接传输。

不接受任意页面代码、文件操作或截图指令。语音 API 请求由 MyPhone 按用户既有配置执行，仅用户点击播放时触发。

## 开发检查

安装 Node.js 与 Microsoft Edge，执行 `npm install` 后运行 `npm test`。测试使用模拟聊天和本机测试页面，不调用实际语音 API。


### 1.7.0 阅读与剧情流程

- 正文生成完成即提供折叠的剧情选项，不依赖语音播放完成。
- 同时跟踪生成开始/结束/停止事件与流式状态，覆盖首字等待和非流式回复。
- 新楼层可点击播放，主动切换旧朗读；剧情选项交给发送按钮后停止旧朗读。
- 生成中禁止发送新选项，旧选项继续核对聊天、楼层和正文版本。
- 需配套新版桌宠；更新扩展后刷新 TT/ST。
